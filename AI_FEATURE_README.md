# 🤖 AI Auto-Reply Feature

The bot now includes an AI auto-reply system that can respond to user questions about casino topics using local open-source AI models.

## ✨ Features

- **Auto-responds** when the bot is mentioned/tagged
- **Detects casino keywords** (casino, bet, gamble, slot, poker, etc.)
- **Conversation memory** - remembers last 10 messages per channel
- **Local AI models** - runs on your machine (no API costs!)
- **Lightweight** - works with 4GB RAM
- **Privacy-focused** - all data stays on your server

## 🚀 Quick Start

### Windows

```powershell
# Run the setup script
.\scripts\setup-ollama.ps1
```

### Linux/macOS

```bash
# Run the setup script
chmod +x scripts/setup-ollama.sh
./scripts/setup-ollama.sh
```

### Manual Setup

1. **Install Ollama**
   - Windows: Download from https://ollama.ai/download
   - Linux: `curl -fsSL https://ollama.ai/install.sh | sh`
   - macOS: `brew install ollama`

2. **Download a model**
   ```bash
   ollama pull llama3.2:1b
   ```

3. **Configure .env**
   ```env
   AI_ENABLED=true
   AI_PROVIDER=ollama
   AI_MODEL_NAME=llama3.2:1b
   AI_BASE_URL=http://localhost:11434
   AI_CHANNELS=
   ```

4. **Rebuild and start**
   ```bash
   npm run build
   npm start
   ```

## 📋 Commands

- `/ai-status` - Check AI system status
- `/ai-clear-history` - Clear conversation history for current channel

## 🎯 How It Works

The bot will respond when:
1. Someone mentions/tags the bot
2. A message contains casino-related keywords
3. Message is in a configured AI channel (or all channels if not specified)

Example triggers:
- `@BotName what are the best slot games?`
- `How do I play blackjack?`
- `What's the house edge in roulette?`

## 🔧 Configuration

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `AI_ENABLED` | Enable/disable AI | `false` |
| `AI_PROVIDER` | AI provider (`ollama`, `openai`, `anthropic`) | `ollama` |
| `AI_MODEL_NAME` | Model to use | `llama3.2:1b` |
| `AI_BASE_URL` | Ollama API URL | `http://localhost:11434` |
| `AI_CHANNELS` | Comma-separated channel IDs (empty = all) | `` |
| `AI_API_KEY` | API key (for OpenAI/Anthropic only) | `` |

### Recommended Models

**For 4GB RAM:**
- `llama3.2:1b` - Fastest, best for low RAM ⭐ RECOMMENDED
- `phi3:mini` - Good balance
- `gemma2:2b` - Slightly larger

**For 8GB+ RAM:**
- `llama3.2:3b` - Better quality
- `llama3.1:8b` - Best quality

### Channel Restrictions

Restrict AI to specific channels:
```env
AI_CHANNELS=123456789012345678,987654321098765432
```

Or allow all channels:
```env
AI_CHANNELS=
```

## 🎨 Customization

### Change System Prompt

Edit `src/ai/ai-manager.ts`:

```typescript

  content: `Your custom personality here...`,
};
```

### Add Keywords

Edit `src/ai/ai-manager.ts`:

```typescript
const casinoKeywords = [
  'casino',
  'bet',
  'your-keyword-here',
];
```

### Adjust Response Length

Edit `src/ai/ai-manager.ts`:

```typescript
const response = await this.provider.generateResponse(messages, 300); // Shorter
```

## 🔍 Troubleshooting

### "Ollama is not available"
- Check if Ollama is running: `ollama list`
- Verify base URL: `curl http://localhost:11434/api/tags`
- Restart Ollama: `ollama serve`

### "Model not found"
- Download the model: `ollama pull llama3.2:1b`
- Check installed models: `ollama list`
- Verify model name in .env matches exactly

### Slow responses
- Use a smaller model (`llama3.2:1b`)
- Close other applications
- Check RAM usage

### High RAM usage
- Use `llama3.2:1b` instead of larger models
- Restart Ollama periodically
- Consider upgrading RAM

## 📊 Performance
