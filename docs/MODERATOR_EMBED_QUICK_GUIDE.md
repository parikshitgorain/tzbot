# Moderator Quick Guide: !embed Command

## What is !embed?

The `!embed` command allows you to post announcements as professional-looking Discord embeds instead of plain text messages.

## How to Use

1. Go to your private announcement channel
2. Type `!embed` at the start of your message
3. Write your announcement content after `!embed`
4. Send the message

The bot will automatically convert it to an embed and post it to all public announcement channels.

## Examples

### Simple Announcement
**You type:**
```
!embed Server maintenance tonight at 10 PM EST. Expect 30 minutes of downtime.
```

**Users see:**
> 📋 **Embed with blue sidebar**
> 
> Server maintenance tonight at 10 PM EST. Expect 30 minutes of downtime.
> 
> *Posted by YourUsername • Today at 3:45 PM*

### Formatted Announcement
**You type:**
```
!embed 🎉 **New Features Released!**

We're excited to announce:
• Enhanced moderation tools
• Improved giveaway system
• Better logging

Try them out now!
```

**Users see:**
> 📋 **Embed with blue sidebar**
> 
> 🎉 **New Features Released!**
> 
> We're excited to announce:
> • Enhanced moderation tools
> • Improved giveaway system
> • Better logging
> 
> Try them out now!
> 
> *Posted by YourUsername • Today at 3:45 PM*

### With Images
**You type:**
```
!embed Check out our new server banner!
```
**Then attach an image**

The image will be included with the embed.

## Tips

- Use **bold**, *italics*, and other Discord markdown formatting
- Add emojis for visual appeal
- Keep messages concise and clear
- Images and attachments are automatically included
- Your username and avatar appear in the footer

## Regular Messages

If you don't use `!embed`, your message will be relayed as normal text (existing behavior).

## Need Help?

Contact a server administrator if you have questions about the announcement system.
