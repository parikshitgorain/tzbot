===========================================
GROQ AI SETUP - VPS COMMANDS
===========================================

Copy and paste these commands on your VPS:

-------------------------------------------
OPTION 1: Automated Script (Recommended)
-------------------------------------------

cd /var/www/tzbot/current && git fetch origin Development && git checkout Development && git pull origin Development && chmod +x deployment/scripts/configure-groq-vps.sh && ./deployment/scripts/configure-groq-vps.sh


-------------------------------------------
OPTION 2: Manual Step-by-Step
-------------------------------------------

# 1. Go to bot directory
cd /var/www/tzbot/current

# 2. Pull latest code
git fetch origin Development
git checkout Development
git pull origin Development

# 3. Install and build
npm install
npm run build

# 4. Verify build
ls -la dist/ai/providers/groq-provider.js

# 5. Edit environment file
nano /var/www/tzbot/shared/.env

# Add/update these lines:
AI_ENABLED=true
AI_PROVIDER=groq
AI_API_KEY=YOUR_GROQ_API_KEY_HERE
AI_MODEL_NAME=llama-3.1-8b-instant

# Remove this line if it exists:
AI_BASE_URL=http://localhost:11434

# Save: Ctrl+X, Y, Enter

# 6. Stop Ollama (optional - saves 2.3GB RAM)
sudo systemctl stop ollama
sudo systemctl disable ollama

# 7. Restart bot
pm2 restart tzbot

# 8. Check logs
pm2 logs tzbot --lines 30


-------------------------------------------
VERIFICATION
-------------------------------------------

# Check logs for success
pm2 logs tzbot --lines 30 | grep -i "AI provider initialized"

# Should see:
# "AI provider initialized" with "provider":"Groq"

# Test in Discord:
# @TZbot what is the rainbet code?

-------------------------------------------
TROUBLESHOOTING
-------------------------------------------

# View full logs
pm2 logs tzbot

# Check bot status
pm2 status

# Check environment
cat /var/www/tzbot/shared/.env | grep AI_

# Restart if needed
pm2 restart tzbot

# Rollback to disabled AI
nano /var/www/tzbot/shared/.env
# Change: AI_ENABLED=false
pm2 restart tzbot
